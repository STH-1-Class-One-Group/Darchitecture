
# proxy/ 디렉토리 파일 명세

> 이 문서는 `server/proxy/`의 역할과 책임을 정의합니다.
> 클라이언트가 외부 API를 직접 호출하지 않고 이 서버를 통해 중계함으로써 API 키 노출을 방지합니다.
> 에이전트가 외부 API 연동 코드를 작성할 때 이 계층의 책임 범위를 참조하기 위한 문서입니다.

---

## 역할 개요

클라이언트(React Native 앱)는 외부 API를 직접 호출하지 않습니다.
모든 외부 API 요청은 반드시 `server/proxy/`를 통해 중계됩니다.

```
클라이언트 → routes/map.js → proxy/ → 공공데이터포털 API
                                ↓
                        API 키 주입 + 응답 가공
                                ↓
                         클라이언트에 반환
```

---

## 책임 범위

### 1. API 키 보호
- 외부 API 호출에 필요한 API 키를 서버 환경변수(`.env`)에서 주입
- 클라이언트 코드 및 응답에 API 키가 노출되지 않도록 차단

### 2. 요청 중계
- 클라이언트 요청을 받아 외부 API로 전달
- 현재 연동 대상: 공공데이터포털 타슈 대여소 API (`routes/map.js GET /stations`에서 호출)

### 3. 응답 가공
- 외부 API 원본 응답에서 앱에 필요한 데이터만 추출하여 반환
- 외부 API 스펙 변경 시 이 계층에서만 수정하여 영향 범위 최소화

### 4. 인증 처리
- 외부 서비스 호출에 필요한 인증 헤더 및 파라미터 관리

---

## 연동 대상

| 외부 서비스 | 용도 | 호출 라우터 |
|------------|------|------------|
| 공공데이터포털 타슈 API | 타슈 대여소 위치 데이터 조회 | `routes/map.js GET /stations` |

**비고:** 추후 국가 탄소중립포인트 제도 연동 시 이 계층에 추가

---

## 규칙

- API 키는 반드시 환경변수에서 참조. 코드에 하드코딩 금지
- 외부 API 응답을 클라이언트에 그대로 전달하지 않고 필요한 필드만 가공하여 반환
- 외부 API 호출 실패 시 적절한 에러 응답을 클라이언트에 반환 (외부 API 에러를 그대로 노출하지 않음)
