
# routes/ 디렉토리 파일 명세

> 이 문서는 `server/routes/` 하위 각 라우터 파일의 역할과 엔드포인트를 정의합니다.
> 각 라우터는 클라이언트 요청(URL)을 받아 `server/core/`의 비즈니스 로직으로 전달하는 입구 역할을 합니다.
> 에이전트가 엔드포인트 추가·수정 시 각 파일의 책임 범위를 파악하기 위한 참조 문서입니다.

---

## auth.js

**역할:** 사용자 인증 라우터

**책임 범위:** 회원가입 및 로그인 요청 처리

| Method | Path | 설명 | 비고 |
|--------|------|------|------|
| POST | `/register` | 회원가입 | 유저 정보 암호화 처리 포함 |
| POST | `/login` | 로그인 | |

---

## ride.js

**역할:** 타슈 이용 세션 라우터

**책임 범위:** 이용 시작·종료 이벤트 처리

| Method | Path | 설명 | 비고 |
|--------|------|------|------|
| POST | `/start` | 이용 시작 기록 | GPS 경로 추적 세션 시작 시점 |
| POST | `/end` | 이용 종료 + 리포트 자동 생성 | 종료 시 `core/report.js` 호출하여 리포트 생성 트리거 |

**연결 core:** `core/ride.js`

---

## report.js

**역할:** 리포트 조회 라우터

**책임 범위:** 이용 완료 후 생성된 리포트 데이터 제공

| Method | Path | 설명 | 비고 |
|--------|------|------|------|
| GET | `/list` | 리포트 목록 조회 | 사용자의 전체 이용 이력 반환 |
| GET | `/:id` | 리포트 상세 조회 | 단건 리포트 데이터 반환 |

**비고:** 리포트 생성은 이 라우터가 아닌 `ride.js POST /end`에서 트리거됨

**연결 core:** `core/report.js`

---

## point.js

**역할:** 포인트 조회 라우터

**책임 범위:** 포인트 잔액 및 적립 이력 제공

| Method | Path | 설명 | 비고 |
|--------|------|------|------|
| GET | `/balance` | 포인트 잔액 조회 | |
| GET | `/log` | 포인트 적립 로그 조회 | MyPageScreen에서 사용 |

**비고:** 현재 포인트 적립만 구현. 사용(차감) 엔드포인트는 미구현 (사용처 추후 결정)

**연결 core:** `core/point.js`

---

## map.js

**역할:** 지도 데이터 라우터

**책임 범위:** 타슈 대여소 위치 데이터 프록시 제공

| Method | Path | 설명 | 비고 |
|--------|------|------|------|
| GET | `/stations` | 타슈 대여소 위치 목록 반환 | 공공데이터포털 API 프록시 (API 키 보호 목적) |

**비고:** 공공데이터포털 직접 호출이 아닌 `server/proxy/`를 통해 중계. API 키는 서버에서만 보유

---

## quiz.js

**역할:** 지식 퀴즈 라우터

**책임 범위:** 퀴즈 문제 제공 및 제출 결과 처리

| Method | Path | 설명 | 비고 |
|--------|------|------|------|
| GET | `/questions` | 퀴즈 문제 목록 조회 | 초기 측정 / 재측정 구분 파라미터 필요 |
| POST | `/submit` | 퀴즈 제출 + KPI 데이터 기록 | 초기 사용자와 일정 기간 이후 사용자 비교용 데이터 저장 |

**연결 core:** `core/quiz.js`

---

## usage.js

**역할:** 사용량 측정 라우터

**책임 범위:** 앱 사용량 데이터 수집

| Method | Path | 설명 | 비고 |
|--------|------|------|------|
| POST | `/log` | 사용량 측정 데이터 수집 | 추후 실제 운영 플랫폼에서의 데이터 수집 경험 축적 목적 |

**비고:** 독립 모듈로 관리. 다른 기능 로직과 의존성 없이 별도 동작하도록 유지

**연결 core:** `core/usage.js`
