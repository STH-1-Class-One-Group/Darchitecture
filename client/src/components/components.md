## components/ 디렉토리 파일 명세

> 이 문서는 `client/src/components/` 하위 재사용 UI 컴포넌트의 역할과 책임을 정의합니다.
> 에이전트가 코드 작성 또는 수정 시 각 파일의 목적과 범위를 파악하기 위한 참조 문서입니다.

---

## Button.jsx

**역할:** 공통 버튼 컴포넌트

**책임:**
- 이용 시작 / 이용 종료 / 제출 등 앱 전반에서 사용되는 버튼 UI 제공
- `label`, `onPress`, `disabled` props를 통해 각 화면에서 재사용

---

## Card.jsx

**역할:** 공통 카드 컴포넌트

**책임:**
- 리포트 항목, 포인트 적립 로그 등 목록형 데이터를 카드 형태로 표시
- children 슬롯 구조로 다양한 화면에서 재사용

---

## MapMarker.jsx

**역할:** 지도 마커 컴포넌트

**책임:**
- 타슈 대여소 위치를 지도 위에 마커로 표시
- MapScreen.jsx 내부에서 대여소 목록을 순회하며 반복 렌더링

---

## RoutePolyline.jsx

**역할:** GPS 경로 시각화 컴포넌트

**책임:**
- 이용 중 수집된 GPS 좌표 배열을 지도 위 경로선(Polyline)으로 렌더링
- MapScreen.jsx 내부에서 사용

**연결 모듈:** `rideModule.js`

---

## ReportCard.jsx

**역할:** 리포트 요약 카드 컴포넌트

**책임:**
- 이동 거리, 탄소 절감량, 적립 포인트 등 이용 1건의 핵심 수치를 카드 형태로 표시
- ReportScreen.jsx 및 ReportListScreen.jsx에서 공통으로 사용

---

## PointLogItem.jsx

**역할:** 포인트 적립 로그 항목 컴포넌트

**책임:**
- 포인트 적립 1건의 금액과 적립 일시를 목록 항목 형태로 표시
- MyPageScreen.jsx의 포인트 적립 로그 목록에서 반복 사용

**비고:** 2차 프로토타입 구현 대상

---

## QuizItem.jsx

**역할:** 퀴즈 문항 컴포넌트

**책임:**
- 퀴즈 1문항의 질문과 선택지를 표시
- 사용자의 선택 상태를 관리하여 QuizScreen.jsx에 결과 전달

**비고:** 2차 프로토타입 구현 대상

---

## PermissionRow.jsx

**역할:** 권한 항목 표시 컴포넌트

**책임:**
- 권한 이름(위치, 알림 등)과 현재 허용 / 비허용 상태를 1행으로 표시
- PermissionScreen.jsx의 권한 목록에서 반복 사용

---
