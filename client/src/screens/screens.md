# screens/ 디렉토리 파일 명세

> 이 문서는 `client/src/screens/` 하위 각 화면 컴포넌트의 역할과 책임을 정의합니다.
> 에이전트가 코드 작성 또는 수정 시 각 파일의 목적과 범위를 파악하기 위한 참조 문서입니다.

---

## AuthScreen.jsx

**역할:** 사용자 인증 화면

**책임:**
- 로그인 / 회원가입 UI 및 로직 처리
- 인증 성공 시 OnboardingScreen 또는 MapScreen으로 라우팅

**비고:** 앱 진입 시 인증되지 않은 사용자에게 최초로 표시되는 화면

---

## OnboardingScreen.jsx

**역할:** 앱 최초 실행 시 초기 설정 화면

**책임:**
- 사용자의 원하는 지역구 선택 (대전 5개 지역구 중 택1) 또는 관광객 여부 선택
- 앱 주요 기능 사용법 안내 (타슈 앱 이용시작 → 본 앱 이용시작 순서 안내 포함)
- 선택 결과를 사용자 초기 설정값으로 저장

**비고:** 회원가입 직후 1회만 표시. 이후에는 MyPageScreen에서 설정 변경 가능 

---

## MapScreen.jsx

**역할:** 타슈 이용의 핵심 화면 (지도 + 이용 세션 관리)

**책임:**
- 타슈 대여소 위치 지도 표시
- 이용 시작 / 이용 종료 버튼 제공
- 이용 중 GPS 경로 실시간 추적 및 지도에 표시
- 이용 종료 후 탄소 절감량 계산 트리거 → ReportScreen으로 이동

**연결 모듈:** `rideModule.js` (이용 세션), `carbonModule.js` (절감량 계산)

**비고:** 일정 시간 정지 감지 시 푸시 알림 발송 ("자전거 이용 종료 하셨나요?")

---

## ReportScreen.jsx

**역할:** 이용 1회 완료 후 결과 리포트 화면

**책임:**
- 해당 이용 건의 이동 거리, 경로, 탄소 절감량, 적립 포인트 출력
- 단건 리포트 표시 (목록 조회는 ReportListScreen에서 처리)

**연결 모듈:** `carbonModule.js`, `pointModule.js`

---

## ReportListScreen.jsx

**역할:** 누적 리포트 목록 조회 화면

**책임:**
- 사용자의 전체 이용 이력 리포트 목록 표시
- 각 항목 탭 시 해당 ReportScreen으로 이동 (상세 조회)

---

## MyPageScreen.jsx

**역할:** 마이페이지 화면

**책임:**
- 사용자 기본 정보 표시
- 유저별 리포트 목록 조회
- 포인트 잔액 표시 *(2차 프로토타입 구현 대상)*
- 포인트 적립 로그 목록 조회 *(2차 프로토타입 구현 대상)*

**연결 모듈:**
서버 API `GET /report/list` 호출
`pointModule.js` *(2차 프로토타입 구현 대상)*

**비고:** 1차 프로토타입에서는 리포트 목록 조회 중점 구현.
포인트 잔액/적립 로그는 UI 껍데기만 구현 후
부가 기능 단계(03.19~03.24)에서 연결 예정

---

## QuizScreen.jsx

**역할:** 탄소중립 지식 퀴즈 화면 *(2차 프로토타입 구현 대상)*

**책임:**
- 초기 퀴즈 진행 (앱 첫 사용 시)
- 일정 사용량 도달 시 재측정 퀴즈 진행
- 퀴즈 결과를 KPI 측정 데이터로 저장 (초기 vs 일정 기간 이후 비교용)

**비고:** KPI 수치 측정 목적의 기능. 핵심 기능이 아닌 부가 기능으로 분류됨

---

## PermissionScreen.jsx

**역할:** 앱 권한 안내 및 현황 확인 화면

**책임:**
- 앱이 요청하는 권한 목록 표시 (위치, 알림 등)
- 현재 허용 / 비허용 상태 확인 UI 제공
- 사용자가 앱 내에서 직접 권한 현황을 파악할 수 있도록 안내

**비고:** 권한 허용/비허용 요청은 OS 팝업에 위임, 이 화면은 현황 조회 및 안내 목적
